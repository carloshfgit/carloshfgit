## Projeto em Destaque

### **UDrive** - Plataforma SaaS & Marketplace
*Plataforma completa de marketplace conectando alunos a instrutores de direção, desenvolvida seguindo os princípios de Clean Architecture.*

<p align="left">
  <a href="https://play.google.com/store/apps/details?id=com.ch_costa.udrive" target="_blank">
    <img src="https://img.shields.io/badge/Google_Play-000000?style=for-the-badge&logo=google-play&logoColor=white" alt="Google Play" />
  </a>
  <a href="https://udriver.com.br" target="_blank">
    <img src="https://img.shields.io/badge/Web_App-2563EB?style=for-the-badge&logo=google-chrome&logoColor=white" alt="Web App" />
  </a>
</p>

* **Mobile:** Desenvolvido em **React Native (Expo)** com TypeScript, Zustand para gerenciamento de estado e TanStack Query v5 para cache e sincronização de dados.
* **Backend:** API assíncrona robusta em **FastAPI (Python 3.12+)** estruturada sob os princípios de Clean Architecture, utilizando PostgreSQL com extensão **PostGIS** para consultas espaciais e SQLAlchemy 2.0.
* **Web App & Admin:** Portais desenvolvidos com **Next.js 16 (App Router)** e React 19, estilizados com Tailwind CSS v4 / shadcn/ui v3 e hospedados em containers de produção no Google Cloud Run.
* **Infraestrutura Serverless:** Fluxos e tarefas assíncronas gerenciados de forma resiliente via **Google Cloud Tasks** (HTTP Push), reduzindo custos e complexidade operacional.
